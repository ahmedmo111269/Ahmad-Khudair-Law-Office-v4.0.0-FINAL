## 2) أرقام الملفات: رئيسي / فرعي / رسمي ✅

- **مصدر عرض واحد:** `js/core/file-number.js` — `formatFileNumber()` مستخدمة في كل التطبيق.
- **العرض للمستخدم:**
  - ملف رئيسي (أكواد `CL-`): `ملف رئيسي: 2/2026` أو الشارة `2/2026`.
  - ملف فرعي (أكواد `LF-`): `ملف فرعي: 1/2026`.
  - إعلانات/سجلات الخدمة (`SR-`): `5/2026` كنوع «إعلان».
  - السنة = سنة الإنشاء، والترقيم يبدأ من 1 لكل سنة، وعدادات الرئيسي والفرعي **مستقلة تمامًا** (عدّادات موجودة أصلًا `client:السنة` و`lf:السنة` — لا تغيير في البنية).
- **الأرقام الرسمية للقضايا** (`1545/2026`) لها دالتها الخاصة `formatOfficialNumber` ولا تُخلط أبدًا بالرقم الداخلي — واختبار آلي يمنع تفسير رقم قضية على أنه رقم ملف.
- **لا تظهر الأكواد التقنية** (`CL-2026-000002` / `LF-2026-000001`) للمستخدم في أي شاشة؛ تبقى في قاعدة البيانات والعلاقات كما هي (فقط في تلميح الشارة للمطوّر).
- **شمولية الاستبدال (تم التحقق بالمسح):** جداول القوائم، بطاقات الملفات، صفحة الموكل، صفحة الملف (الترويسة/مسار التنقل/آخر نشاط/ملخص)، صفحة القضية/السجل، نتائج البحث المركزي ولوحة الأوامر، القوائم المنسدلة (lookup)، مركز العمل، تقارير الاستحقاق، وسجلات الخدمة — **صفر** مواضع عرض متبقية خارج الاختبارات.
- دعم إضافي: الصيغة القديمة `2026/0001` تُعرض موحدة، والأرقام العربية (`٢/٢٠٢٦`) تُطبَّع.

## 3) نظام البطاقات الموحّد ✅

- **بانية واحدة `card()`** في `js/ui/card.js` + `css/cards.css` بدل التصاميم المتفرقة:
  - أحجام: `sm` / `md` / `lg` / `full`.
  - فتح/طي **محفوظ لكل مستخدم** (`ui:cards`)، بالنقر على الزر أو على الترويسة.
  - ترتيب بصري ثابت: عنوان ← معلومة أساسية (شارة/عداد) ← تفاصيل ← إجراءات.
  - أزرار إجراءات موحدة المكان والشكل + **قائمة (⋯)** للإجراءات الزائدة (إغلاق بالنقر خارجها وEscape).
  - شارات حالة بنغمات (`ux-badge--ok/warn/danger/info`).
  - حالات موحدة: **تحميل (هيكل عظمي) / فراغ (رسالة + إجراء) / خطأ (إعادة محاولة) / نجاح**.
- **لوحة الرئيسية** أعيد بناؤها بالكامل على النظام (بطاقات إحصاءات، اختصارات، أجندة اليوم) — بقية الصفحات ترث النظام عبر `bindCards` في كل تنقل.
