# بيت واحد لكل معلومة — مكتب اليوم

> كل معلومة لها بيت أساسي واحد. إذا ظهرت في مكان آخر فهي **رابط أو اختصار فقط**، لا نسخة من المنطق.
> القرار يأتي من دالة مركزية واحدة: `buildFocusModel` في `js/services/focus-engine.js`.

| المعلومة | بيتها | المصدر الوحيد للمنطق | ملاحظات |
|---|---|---|---|
| الخطوة التالية + سببها + «ثم» | بطاقة «الآن» (`focusHtml`) | `focus-engine` → `next` | سبب الظهور نصه من `REASON_TEXT` |
| جدول اليوم + التعارضات | شريط اليوم (`timelineHtml`) | `focus-engine` → `timeline`, `conflicts` | شريحة «تعارض N» داخل الشريط |
| ما يحتاج قرارًا | طابور القرارات (`attentionHtml`) | `focus-engine` → `groups` | ثلاث طبقات، حد 5 لكل طبقة |
| منذ آخر زيارة | قسم «منذ آخر زيارة» | `home-visit.js` → `sinceChanges` | الكتابة عند المغادرة فقط |
| الأرقام | شريط الأعداد + ملخص العمل المطوي | `counts` / `dashboardBrief` | لا أرقام بلا إجراء |
| البحث / الفلاتر / Saved Views | مركز العمل | `work-query.js`, `work-config.js` | لم تتغير |
| الإضافة السياقية والطبيعية | Quick Add (`+ إضافة`) | `modules/quick-add.js` → `routeContext` / `runQuickAction` / `parseNaturalQuickAdd` | يحفظ سياق الملف/القضية؛ الرئيسية تضع تاريخ اليوم افتراضيًا؛ الإدخال الطبيعي يعرض معاينة ويفتح النموذج الحالي فقط بلا كتابة مباشرة | النماذج والخدمات القائمة تظل مالكة للحفظ |
| نص السبب | `work-config.js` → `REASON_TEXT` | — | لا نص سبب داخل المكونات |
| نص الإجراء | `work-config.js` → `ACTION_LABEL` / `actionKeyFor` | — | لا إجراء بلا حالة سجل |
| Focus | وضع عرض لنفس بطاقة «الخطوة التالية» | `home.js` toggle + `cockpit.js` markup؛ `focus-engine` يظل مصدر العنصر | من دون مؤقت أو شاشة جديدة؛ يحتفظ بالحالة عند الإنجاز المحلي إلى أن ينتقل المحرك للعنصر التالي |
| اختيار «يومي» | عرض مركّب في مركز العمل | `my-day.js` → اختيار/انتهاء اليوم المحلي | تفضيل يومي؛ العرض يقرأ العناصر القائمة ولا ينشئ طبقة بيانات |
| «ليس الآن» | ظهور العنصر في Work Center | `work-hides.js` → صلاحية/expiry/Undo؛ `work-actions.js` يربط الفعل | preferences فقط؛ لا تعديل للسجل؛ الحرج والمتأخر غير قابلين للإخفاء |
| إشارة تحضير الغد | ملاحظة واحدة في «مكتب اليوم» | `tomorrow-prep.js` → candidate؛ `home.js` → العرض | بعد وقت المستخدم فقط، وعند وجود فجوة بيانات قابلة للتصرف |
| نسخ خلاصة اليوم | قائمة ⋯ في Work Center | `work-center.js` → `copyDaySummary` | يبقى فعلًا واحدًا؛ لا منطق نسخ في الصفحة الرئيسية |
| عداد تأجيل العمل الأصلي | لوحة «مكتب اليوم» | `work-config.js` threshold + `dashboard.js` overlay join المجمّع | مصدر `postponeCount` يبقى work-items؛ لا نقل سجل ولا N+1 |
