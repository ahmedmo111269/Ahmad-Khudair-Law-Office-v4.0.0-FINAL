# تدقيق قسم الملفات والموكلين — File Cockpit (مرحلة A)

**التاريخ:** 2026-10-09 · **النطاق:** قائمة الملفات، صفحة الموكل (`cfile:`)، صفحة الملف القانوني (`file:`)، نظام الطي، Quick Add، التنقل، الأداء.

## 2. ما وُجد موجودًا فعليًا (لا إعادة اختراع)

1. **نظام طي مركزي واحد** (`collapse-state` + `collapsible` + اندماج datagrid/cards/page-layout) — طُوّر فقط.
2. **`registerPageLayout` / SectionLayoutManager** — نظام الترتيب والإظهار الموحّد لكل الصفحات، ونوافذ «تخصيص الصفحة».
3. **آلية الخطوة التالية في الملف** (`fileCockpitHtml`) — نفس منطق الرئيسية/مركز العمل فيما يخص الملف (بيانات مسجلة فقط)، مع `reasonCode`/`REASON_TEXT` في `work-config.js` لنصوص السبب في الرئيسية. لا منطق «تالي» ثالث — استُخرج `fileNextStep` كدالة مشتركة للبطاقة والشريط المضغوط.
4. **Quick Add سياقي** يمرر `fileId` ويمنع اختيار الملف المتكرر عند وجود سياق.
5. **`buildFocusModel`/`clientWorkspaceHtml`** لمركز عمل الموكل («يحتاج انتباهك» + «الآن»).
6. **Undo** عبر toast «تراجع» في `bindCockpit` (completeItem/reopenItem).
7. **منع النقر المتكرر**: `openEntityForm` يعطّل زر الحفظ أثناء الإرسال.
8. **البحث العربي** (`normalizeArabic`/`normalizeDigits`): NFKC + أ/إ/آ/ٱ←ا + ى←ي + تشكيل + تطويل + أرقام عربية/هندية.

## 3. الفجوات التي عولجت (ملخص)

- عقد قابلية الطي: ملخص حي، تنبيهات دائمة، فتح مؤقت، استعادة الافتراضي، وضع هاتف، أكورديون، أوامر «طي الكل/فتح الكل».
- قائمة الملفات: شرائح حالة، ملخص فلاتر قابل للإزالة، سابق/تالي، عمودا «الخطوة التالية».
- صفحة الموكل: واتساب/اتصال، أولوية «يحتاج متابعة»، تنبيه مطوي.
- File Cockpit: إجراء أساسي + قائمة ⋯، نواقص الملف، شريط مضغوط، مناطق تبويبات (5 مناطق + شرائط فرعية)، cache للمناطق، نسخ ملخص، فحص قبل الإغلاق/الأرشفة، وضع تركيز، «تغيّر منذ زيارتي».
- أداء: لا استعلام IndexedDB عند الطي/التوسيع؛ تركيب التبويبات الثقيلة عند أول فتح فقط.

## 4. مخاطر موثقة

- **مفتاح تفضيل جديد واحد** `ui:file-last-tab` (تبويب الملف الأخير، عام لكل الصفحات) + `ui:focus-mode` (وضع التركيز) — أبسط من مفتاح لكل ملف، ولا يمس البيانات.
- **فهرس «جلسة قادمة» في شريحة القائمة**: استعلام واحد محدود (≤5,000 جلسة من اليوم فما بعد) مع كاش 60 ثانية في الجلسة — لا Full Scan.
- **«تغيّر منذ زيارتي»**: يعتمد `activityLog` + وقت زيارة محفوظ بنفس آلية الرئيسية (`ui:home:last-seen` scope=`file:<id>`) — لا حقل `lastSeenAt` على السجل، ولا Schema جديد.
