# خطة الاختبار اليدوي — RC1

## المسار الحرج
1. فتح التطبيق وإنشاء/فتح قاعدة بيانات.
2. إنشاء موكل ثم فتح سجل الموكل.
3. إنشاء ملف وربطه بالموكل.
4. إنشاء قضية داخل الملف.
5. إضافة جلسة وإجراء إداري وتحقق من ظهور النشاط.
6. إضافة حكم ثم تنفيذ.
7. اختبار رجوع/إغلاق كل نموذج وسجل.
8. اختبار البحث العربي والرقمي.
9. اختبار الفرز والتصفية المركبة.
10. اختبار النسخ الاحتياطي والاستعادة إلى قاعدة جديدة.
11. إنشاء قاعدة ثانية والتأكد من عزل البيانات ثم العودة للأولى.

## معيار النجاح
- لا فقد بيانات.
- لا ظهور لبيانات قاعدة أخرى.
- لا زر أساسي بلا وظيفة.
- الرجوع يعيد المستخدم للسياق السابق، والإغلاق يعيد للرئيسية.
- فشل أي عملية مركبة لا يترك كتابة جزئية.

> الاختبار اليدوي على متصفح فعلي هو المرجع النهائي قبل الإنتاج.
