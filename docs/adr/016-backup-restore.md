# ADR-016: النسخ الاحتياطي والاستعادة

- النسخة الاحتياطية هي JSON كاملة للقاعدة النشطة.
- الإصدار الحالي Backup v2 ويحتوي على جميع الـ stores المعروفة، وإصدار التطبيق والمخطط وSHA-256 عند توفر Web Crypto.
- الاستعادة المدعومة هي **استبدال كامل** للقاعدة النشطة داخل IndexedDB transaction واحدة.
- لا يوجد استيراد جزئي صامت؛ الملف الناقص أو غير السليم يُرفض قبل بدء المعاملة.
- فشل المعاملة يؤدي إلى rollback طبيعي من IndexedDB.
- يظل الحذف من خارج التطبيق غير مستخدم.
