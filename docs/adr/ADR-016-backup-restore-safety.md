# ADR-016 — Backup, Restore & Database Safety

## القرار
- النسخ الاحتياطية تحمل format/version/schemaVersion وبصمة SHA-256 للـstores.
- لا تُستعاد نسخة قبل التحقق من البنية والبصمة.
- الاستعادة إلى قاعدة جديدة هي المسار المفضل ولا تعدّل القاعدة الحالية.
- الاستعادة فوق القاعدة الحالية تنشئ نسخة أمان من القاعدة الحالية أولًا وتحتاج تأكيدًا صريحًا.
- اختلاف Backup version أو Schema version يمنع الاستعادة بدل التخمين أو إسقاط البيانات.
- فشل الاستعادة إلى قاعدة جديدة يترك ملف قاعدة الاستعادة بحالة `recovery-failed` للمراجعة ولا يحذف قاعدة أخرى.

## السبب
بيانات المكتب القانونية عالية الحساسية وقيمة الاستمرارية أعلى من سهولة الاستعادة السريعة. لا يجوز أن يؤدي ملف غير صالح أو اختلاف بنية غير معروف إلى كتابة غير قابلة للعكس.
