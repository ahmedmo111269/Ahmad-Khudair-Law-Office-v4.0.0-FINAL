## نظام إدارة ومتابعة دورة الملفات القانونية

تطبيق ويب محلي Offline-first لإدارة دورة العمل داخل مكتب المحاماة. يعمل على GitHub Pages ولا يحتاج إلى Backend أو API أو Firebase أو Supabase.

## النطاق
هذه النسخة تجمع الأساس والوظائف التشغيلية الرئيسية: الموكلون، الملفات، القضايا، الخصوم، التوكيلات، الجلسات، الإجراءات والمهام، المواعيد، الاتصالات، الملاحظات، الأحكام، **قسم التنفيذ** (مدني/جزائي/أسرة: سلسلة الأحكام، فترات القيمة، التحصيل والتخصيص، الفروق والتسويات، التوكيلات، الرصيد المفكَّك)، الأتعاب، دفعات الأتعاب، مراجع المستندات، البحث، النسخ الاحتياطي، وقواعد البيانات المتعددة.

لا يحتوي المشروع على حاسبات الاستئناف أو النقض أو المواعيد القانونية أو المواعيد العمالية أو متجمد النفقات أو مستحقات العمال؛ هذه تطبيقات مستقلة.

## التنقل (v5.2.0)
القائمة الجانبية لم تعد على الجانب: صارت **شريط تنقل أفقيًا أعلى البرنامج بعرض مساحة العمل بالكامل**، بنفس عناصر القائمة السابقة ومساراتها وأيقوناتها (29 مسارًا في 6 مجموعات — منها «مركز التنفيذ» و«المزامنة») وبلا حذف أي عنصر. كل مجموعة تبويب، والضغط عليه يفتح لوحة منظمة بعناصره (أو ينقله إلى تبويب «المزيد» تلقائيًا عند ضيق المساحة — بلا أي تمرير أفقي للصفحة). الشريط **ثابت أثناء التمرير وقابل للطي** (مع زر إظهار واضح وتوسّع المحتوى لكامل العرض)، ويعمل على سطح المكتب والمتوسط والهاتف، بدعم RTL كامل، ومن زر **«تخصيص»** يمكنك إظهار/إخفاء أي تبويب أو عنصر وترتيبها (يُحفظ في `ui:topnav-config`). التفاصيل في `PROJECT_MAP.md` و`CHANGELOG.md`.

## التشغيل
1. ارفع محتويات المجلد إلى Repository.
2. اجعل GitHub Pages يعمل من branch `main` ومجلد `/root`.
3. افتح `index.html` عبر GitHub Pages. يفضل HTTPS؛ بعض خصائص PWA/Storage لا تعمل من `file://`.

## التثبيت على الهاتف (Android / PWA)
البرنامج قابل للتثبيت كتطبيق: Manifest كامل + Service Worker + أيقونات Android (بما فيها Maskable) + شاشة إقلاع، وزر تثبيت في الإعدادات مع خطوات يدوية بديلة.
- **يعمل بلا إنترنت** بعد أول تحميل: كل ملفات التطبيق تُخزَّن في كاش مُرقَّم بالإصدار، وكل بيانات المكتب في IndexedDB على الجهاز — ولا تدخل بيانات المستخدم Cache Storage إطلاقًا.
- **زر الرجوع في Android** يتصرف بمنطق: يغلق النافذة/الطبقة المفتوحة، ثم يرجع للشاشة السابقة، ثم يخرج من التطبيق — بلا فقد نموذج أو خروج مفاجئ.
- **التحديث** ينتظر موافقتك («تحديث الآن») ولا يستبدل الكود أثناء العمل، وتبقى البيانات والتفضيلات والتخصيصات كما هي.
- الدليل الكامل وحدود التحقق ومسار التغليف بـPWABuilder/TWA في [docs/ANDROID-PWA.md](docs/ANDROID-PWA.md).

## التخزين
كل قاعدة بيانات مستقلة لها اسم داخلي يبدأ بـ `AhmadKhudairLawOfficeDB__`. سجل القواعد في localStorage، والبيانات التشغيلية في IndexedDB. حذف ملف القاعدة من Registry لا يحذف قاعدة IndexedDB نفسها.

## المزامنة والعمل دون اتصال
العمل المحلي يعتمد على IndexedDB ويستمر دون إنترنت. المزامنة الحالية يدوية بين الأجهزة عبر حزم ملفات مشفرة، مع معاينة وتأكيد، نسخة أمان قبل التطبيق، Tombstones ومراجعة تعارضات صريحة؛ لا يوجد نقل سحابي أو تلقائي. راجع [دليل المزامنة والعمل Offline-First](docs/SYNC-OFFLINE-FIRST.md) لخطوات التبادل وحدود حماية النسخ الاحتياطية.

## الهوية والبيانات
كل السجلات التشغيلية تستخدم IDs نصية محلية، وتحتوي على createdAt/updatedAt/version، مع soft delete حيث يلزم. البحث العربي يحتفظ بالقيمة الأصلية ويستخدم قيمة normalized مستقلة.

## قواعد مهمة
- File وحدة العمل الإدارية، وCase وحدة العمل القضائية.
- العلاقات بين الموكل والملف/القضية Many-to-Many.
- رقم الملف يولد بواسطة Counter داخل نفس Transaction مع إنشاء الملف.
- حذف ملف له قضية غير محذوفة ممنوع.
- archive وclosed وsoft delete حالات مختلفة.
- لا تعتمد الواجهة على `location.reload()` لتحديث الحالة.

## الاختبارات
افتح `tests.html` من GitHub Pages لتشغيل اختبارات التطبيع والتحقق الأساسية. اختبارات المتصفح وIndexedDB المتقدمة يجب تنفيذها في بيئة HTTP/HTTPS.

## ملاحظة الأداء
البنية تفصل Repository عن Storage Adapter وتدعم إضافة SQLite/Backend مستقبلًا. هذه النسخة لا تدعي أن تحميل كل سجلات المتجر في الذاكرة مناسب لملايين السجلات؛ مرحلة Performance Hardening يجب أن تستبدل الاستعلامات الكبيرة بcursor/keyset pagination وتنفذ اختبارات 100K+ على الأجهزة المستهدفة.
